Bank Loan Application Tracking System — Practice ProjectA personal practice project built to learn and demonstrate Business Analyst / Product Owner tools: Jira, Agile & Scrum, Postman, Confluence, and draw.io — modeled on a realistic fintech scenario (inspired by how a company like Finastra manages loan features).1. Project IdeaA bank wants a new digital feature: customers should be able to apply for a personal loan online, track its status, and receive notifications at each stage — instead of visiting a physical branch. This repository documents how I approached that scenario as a Business Analyst / Product Owner, end to end, using industry-standard tools.2. How I approached it (My Process)Defined the problem — Wrote a one-paragraph business goal: reduce loan application processing time from 3 days (branch visit) to under 10 minutes (digital application).Wrote the BRD in Confluence — Captured the business need, scope, and out-of-scope items before touching Jira, ensuring the team had a single source of truth for why we were building this.Broke it into Jira Epics and Stories — Created one main Epic ("Digital Loan Application") and split it into 6 user stories with clear acceptance criteria (see /jira).Planned 2 sprints — Sprint 1: Application submission + document upload. Sprint 2: Status tracking + notifications (see sprint plan in /jira).Modeled the process visually in draw.io — Created a swimlane diagram showing the interactions between the customer, bank system, and credit-check service so developers and stakeholders could agree on the flow before coding began.Tested the underlying API in Postman — Since "check loan status" relies on an API call under the hood, I built a small Postman collection against a public test API to simulate and validate the request/response flow a developer would build.Tracked progress like a real sprint — Moved stories through To Do $\rightarrow$ In Progress $\rightarrow$ Done, and wrote a short retrospective note outlining what I would do differently next time.4. Tools mapped to real use in this projectAgile/Scrum — Structured the entire project into 2 sprints complete with sprint goals, a backlog, and a retrospective (see /jira/sprint_plan.md).Jira — Formatted epics and user stories in Jira's native structure so they can be directly imported (/jira/epics_stories.csv).Confluence — Structured the BRD (/confluence/BRD.md) like a standard Confluence documentation page, complete with linked Jira references.Postman — Configured /postman/loan_status_api.postman_collection.json so it can be imported directly into Postman to execute sample requests.draw.io — Created /diagrams/loan_process_flow.drawio, which can be opened directly at app.diagrams.net to view or edit the swimlane diagram.5.
